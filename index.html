Telegram Bot Alert

Recommended • 100% Free • Instant
How to get Telegram Token & Chat ID (2 mins)
  1. Open Telegram, search for @BotFather, and click Start.
  2. Send /newbot, choose a bot name & username, and copy the API Token.
  3. Search for your newly created bot in Telegram, open it, and press /start.
  4. Open this link in your browser:
    https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
  5. Find "chat":{"id": 123456789} — that number is your Chat ID.

How to get CallMeBot API Key (1 min)
